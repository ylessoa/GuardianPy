Contribuir a GuardianPy Community
Gracias por ayudar a mejorar GuardianX. Este proyecto acepta solo capacidades defensivas.

Flujo recomendado
Crea un issue describiendo la mejora o bug.
Crea una rama corta: feature/nombre o fix/nombre.
Añade tests cuando cambies el motor de detección, cuarentena o actualizador.
Ejecuta:
bash 
python -m pytest -q
python -m guardianx.cli full .
Reglas de seguridad
No se aceptan aportes que añadan explotación, evasión, persistencia ofensiva, robo de credenciales, payloads, loaders o instrucciones de daño. Las muestras deben ser inofensivas y sintéticas.
