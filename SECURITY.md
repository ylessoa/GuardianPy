Política de seguridad
GuardianX Community es una herramienta defensiva. Si encuentras una vulnerabilidad:

No publiques exploits funcionales.
Abre un reporte privado en GitHub Security Advisories cuando el repositorio esté publicado.
Incluye impacto, pasos de reproducción seguros y versión afectada.
Alcance
Motor de escaneo.
Cuarentena.
Actualización de firmas.
Interfaz y empaquetado.
Fuera de alcance
Uso contra terceros sin autorización.
Muestras de malware reales adjuntas al repositorio.
